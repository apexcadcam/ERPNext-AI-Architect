# agents/

## Purpose

**Phase 3 — not yet active.** This folder exists now so the repository's intended shape is visible from day one, per the mandatory order in [ROADMAP.md](../ROADMAP.md): Research → Rules → Skills → Agents → MCP. It stays empty until [`skills/`](../skills/) has enough building blocks to compose.

## What belongs inside (once active)

A persona that composes one or more existing skills to carry out broader, more autonomous work, plus how those skills are sequenced.

## What does NOT belong inside

Any judgment or shortcut not already present in the skills it composes. An agent that "knows something extra" has broken traceability back to `rules/`.

## Typical lifecycle

Created once a class of work reliably requires chaining multiple existing skills together → tested → retired if its skills are superseded or the task becomes irrelevant.
