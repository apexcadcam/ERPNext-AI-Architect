# anti-patterns/

## Purpose

Named, recurring bad solution shapes worth recognizing across more than one rule — the mirror of a rule's "Bad Pattern" section, pulled out on its own once the same mistake shows up more than once.

## What belongs inside

A short, named description of a mistake that has recurred — what it looks like, why it's tempting, which rule(s) it violates.

## What does NOT belong inside

A one-off mistake seen exactly once. Note that in the relevant rule's own Bad Pattern section (or in `research/` if no rule exists yet) — only pull it out here once it's shown up in a second, unrelated place.

## Typical lifecycle

Stays empty until the same mistake is seen twice → written up once, named → referenced by every rule it violates instead of being re-described in each one.
