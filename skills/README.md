# skills/

## Purpose

**Phase 2 — not yet active.** This folder exists now so the repository's intended shape is visible from day one, per the mandatory order in [ROADMAP.md](../ROADMAP.md): Research → Rules → Skills → Agents → MCP. It stays empty until `rules/` has enough proven rules covering a recurring task end to end.

## What belongs inside (once active)

A packaged, repeatable procedure for one recurring task, built entirely by composing existing files in [`rules/`](../rules/) — e.g., "add a field the upgrade-safe way," walking through the relevant rules in order.

## What does NOT belong inside

Any judgment not already written down as a rule. A skill is only allowed to *apply* rules, never to introduce a new architectural opinion of its own.

## Typical lifecycle

Created only after a task has been handled manually, by hand, against the rules a few times → packaged as a skill → deprecated if its source rules are deprecated.
